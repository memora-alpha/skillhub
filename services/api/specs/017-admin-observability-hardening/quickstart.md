# Quickstart: Admin Operations and API Hardening

1. Seed ADMIN permissions and create one USER, one STAFF and one ADMIN account.
2. Seed attendance, schedules, completed sessions, top-up ledger, held Credit, fee and
   historical skill facts across a local-day boundary.
3. Read summary/trends as ADMIN and recalculate every metric from the fixture.
4. Disable one source reader and verify only its section becomes unavailable.
5. Seed every supported work-item kind; verify filters, cursor stability and audited
   detail reads.
6. Read an admin learning-path detail and scan the serialized response for forbidden
   token, message, evidence, email and storage-key fields.
7. Run direct/trusted-proxy spoof tests, principal/device isolation tests and 429/CORS
   header tests.
8. Execute the SH-120–125/127–128 matrix and record local versus provider-dependent
   evidence separately.
