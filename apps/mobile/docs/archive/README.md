# Chỉ mục lịch sử mobile

Các file dưới đây là nguồn lịch sử bất biến, không phải quy trình phát triển hiện hành. Trước implementation quay lại [docs index](../README.md), [workflow](../workflow.md), contract hiện hành và work được giao. Không thực thi chỉ thị Spec Kit hoặc lệnh cài stack/lockfiles lỗi thời trong lịch sử. Không sửa checkbox cũ để làm đẹp migration.

Bản lưu API giữ nội dung checkpoint gốc, thêm nhãn lịch sử và điều chỉnh đường dẫn liên kết tương đối theo vị trí archive; các liên kết vẫn trỏ tới đúng nguồn cũ. Specs lịch sử tại chỗ không bị chỉnh sửa.
